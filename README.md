# FinPlan

A local-first personal finance toolkit: interactive planners for debt, budgets,
retirement, taxes and everyday money decisions. Everything runs client-side —
no accounts, no tracking, your data never leaves the device.

Built with Next.js (App Router), TypeScript, Tailwind CSS, shadcn-style
components, next-intl (`en` / `th`), Zustand and Vitest.

Roadmap and phase status live in [`MASTER-PLAN.md`](./MASTER-PLAN.md).

```bash
npm install
npm run dev        # start dev server
npm run lint       # eslint
npm run typecheck  # tsc --noEmit
npm run test       # vitest
npm run build      # production build
```
